# 第17弾 期外収縮 ―「1拍だけ早い」を見分ける

16弾（頻拍のシームレス波形）の続き。形式は同じで、**いくつかの波形を1本で紹介しながら、どれもカメラを切らずに流し続ける**。

- つながり：PSVT（16弾）の多くは、1拍の心房期外収縮（PAC）から始まる。「頻拍を見た次は、その引き金を見る」
- 新しい見せ方：**止まらない「洞結節の時計」**。画面の下で、洞調律のP波の目盛りを最初から最後まで刻み続ける
  - PVC：目盛りから外れても、次の拍は元の目盛りに戻る。休みがちょうど2目盛り（代償性休止）
  - PAC：目盛りそのものが前にずれる。休みは2目盛りより短い（非代償性）
- 尺：88.0秒。1080×1920、30fps。カメラは最初から最後まで紙送りと同じ **25mm/秒** で流す（寄り・引きだけを変える）
- 色（3つまで）：正常の緑／この回の色 = 水色 `(110,190,255)`（期外収縮）／赤（報告の目安）。PACとPVCは色ではなく「上から／下から」の矢印とラベルで分ける
- 画面の作りは16弾にそろえる（この案を書いた時点で16弾の動画は見られていない）

## 1. 波形の並び（帯＝世界座標、t秒 = 画面の時刻）

共通の時計：P-P 800ms（75/分）。数値はどれもこの波形での一例で、**画面に出す値はモデルからの実測に置き換える**。

| 区間 | 並べるもの | ループの単位（R-R, 秒） | 確認すること |
|---|---|---|---|
| 0–8 | 洞調律の途中に PVC 1つ | 0.80 …, 0.50, 1.10, 0.80 … | hook 用 |
| 8–14 | 洞調律 | 0.80 | 時計の基準 |
| 14–30 | PAC の単位 × 5 | 0.80, 0.80, **0.55**, 0.90（計 3.05） | 0.55＋0.90＝1.45 ＜ 2×0.80 → 非代償性。時計は1回ごとに 0.15秒 前へずれる |
| 30–46 | PVC の単位 × 5 | 0.80, 0.80, **0.50**, 1.10（計 3.20） | 0.50＋1.10＝1.60 ＝ 2×0.80 → 代償性。PVCの 0.30秒後に来る洞のPは T波に隠れる |
| 46–51 | 二段脈 × 3 | 0.50, 1.10（計 1.60） | 1拍おきに PVC |
| 51–56 | 三段脈 × 2 | 0.80, 0.50, 1.10（計 2.40） | 2拍おきに PVC |
| 56–59 | 2連発 × 1 | 0.80, 0.80, 0.50, 0.45, 0.65（計 3.20） | 0.50＋0.45＋0.65＝1.60。2つめの PVC の 0.65秒後の洞のPは伝わる想定（**要検算**：不応期の扱い） |
| 59–88 | 洞調律 | 0.80 | 注意カード・まとめの後ろで流し続ける |

### シームレスにする決まり
- 型の切り替えは、必ず**洞調律の拍の上**で行う。PVC 系（二段脈・三段脈・連発）は洞の時計を乱さないので、切り替えても時計の目盛りは連続したまま
- PAC は時計をリセットする。ずれた目盛りは古い目盛りを薄い残像で残し、新しい目盛りを水色で刻み直す（「時計が前にずれた」が目で見える）
- カメラは `ctr_mm(t) = ctr0 + 25*t + off(t)`。カット間は `cam0 = 前のカットの cam1`
- **ループ**：最後のコマと最初のコマを同じ絵にする。PAC で時計が合計 0.75秒 ずれるので、最後のカットで `off` を少しずつ動かし、**最後の洞調律の R 頂点が、最初のコマの R 頂点と同じ画面位置**に来るようにする（洞調律は 20mm 周期なので、ずれを 20mm の中で吸収できる）
- 保存カードは波形の上に重ねて出し、最後の 0.6秒で消す（カードの文字にも OUTF）
- 効果音：拍ごとに「ピッ」。PVC は少し低い音にする（声を使わずに「違う拍」がわかる）

## 2. カット構成（88.0秒）

カットのつなぎ目：**8.0 / 14.0 / 30.0 / 46.0 / 62.0 / 76.0**（qc.py に渡す）

| 秒 | カット | 画面 | 主役の印 |
|---|---|---|---|
| 0.0–8.0 | **hook** | 一定の「ピッ、ピッ」。下に時計の目盛り。4.5秒ごろ、1拍だけ早く、広い拍が来る（音も低い）。目盛りから外れた拍に水色の丸 | 外れた拍 |
| 8.0–14.0 | **over** | 「上から来る（心房）か、下から来る（心室）か」。見分けは3つ：①早い拍の前に P'があるか ②QRSの幅 ③休みの長さ（時計で測る） | 3つの番号 |
| 14.0–30.0 | **feat① PAC** | 早いP'に「P'」の文字（形がふつうのPと違う）。QRS は細い。休みを時計で測ると2目盛りに届かない → 目盛りが前にずれる | ずれる目盛り |
| 30.0–46.0 | **feat② PVC** | P'なし、QRSが広い、Tが逆向き。隠れた洞のPの位置に点線の目盛り。休みがちょうど2目盛りで、次の拍は元の目盛りに戻る | 2目盛りのバー |
| 46.0–62.0 | **feat③ 並び方** | 二段脈 → 三段脈 → 2連発を切らずに流す。左上のラベルだけ切り替える。二段脈の区間で「モニター 75／脈 約38」の注記 | 並び方のラベル |
| 62.0–76.0 | **caution** | 画面を暗くして落とし穴3枚＋報告の目安（`OUTF`/`DIMF`で頭と終わりの暗さを戻す） | — |
| 76.0–88.0 | **end** | まとめカード → 保存カード → 0.6秒で消えて、洞調律だけの最初のコマへ | — |

`※ 数値はこの波形での一例` は y ≤ 1545。透かし（右下 y=1562）と重ねない。

### 落とし穴カード
1. **QRSの広い PAC は、PVC に見える**（変行伝導）
   早い拍の前の T波が、ほかの T波と形が違えば、そこに P'が隠れている
2. **伝わらなかった PAC は、「脈が止まった」ように見える**
   洞停止や房室ブロックと思う前に、休みの直前の T波を見る
3. **二段脈では、モニターの心拍数と脈拍が合わない**
   PVC の拍は脈として触れないことがある。脈は自分の指で数える

### 報告の目安（カードの下段）
連発する／形が何種類もある／T波の上に乗る（R on T）／急に増えた／症状がある
→ 意識・血圧・症状を確認して報告。K・Mg の値もあわせて見る（電解質シリーズとつながる）

### まとめカード（3ブロック）
- 見出し：**期外収縮は「上から」か「下から」か**
- 枠の中：
  - PAC：P'がある／QRSは細い／休みは短め（時計がずれる）
  - PVC：P'がない／QRSが広い／休みはちょうど2拍ぶん
  - 並び方：二段脈・三段脈・連発。脈は指で数える
- 保存の一言：**1拍だけ早かったら、時計で測る。保存して、見返してね**

## 3. ナレーション（通常スピード・約45秒ぶん／残りは間）

数字は画面に出すので、声は意味だけを言う。

### 0.0–8.0 hook

- 2.60 リズムは、一定。

- 6.40 これが、期外収縮。

### 8.0–14.0 over
- 8.40 上から来たのか、下から来たのか。

- 83.60 保存して、見返してね
- （85.0 以降は声なし。拍の音だけで最初につなぐ）

### 言い回しの注意
- **「PVC は危ない」と言い切らない。** 単発で症状がなければ、経過観察になることが多い。危ないのは「目安」に当てはまるとき
- **「代償性休止があれば PVC」と言い切らない。** 典型の話。PAC でも休みが長いことや、PVC で休みがない（間入性）こともある → キャプションで補う
- 「洞結節は、何も知らずに」は比喩。PVC が洞結節までさかのぼらないので、洞のリズムがそのまま続く、という意味
- 「脈が半分」は二段脈で PVC の拍が脈として触れないときの話。いつもではない
- Lown 分類は古いので名前は出さない。「報告の目安」とする

### 声の指定
- 「……1拍だけ、早い。」は、モニターを見て気づいた声。小さく
- 「洞結節は、何も 知らずに 刻み続けます。」は目盛りが刻まれるテンポに合わせて、ゆっくり
- 「ただし、落とし穴もあります。」は少し声を落として、ていねいに

## 5. 作る前の残作業

1. **医学の裏取り**（この環境からは LITFL に接続できなかった）：代償性と非代償性、変行伝導、伝わらない PAC、間入性 PVC、二段脈での脈の欠損、報告の目安。出典は台本の末尾に残す
2. **エンジン**：`ecg.beats_at` は全拍が同じパラメータ。**拍ごとにパラメータを変えられる版**（例：`beats_mixed(xs, [(r, P), ...])`）を足す。PVC の形の目安：`p_amp=0, r_dur≈0.10, s_dur≈0.07, r_amp≈1.3, st≈0.03, t_amp≈-0.45, t_dur≈0.24`（QRS 120ms 以上になるか `measure` で確認）。この部品は20本計画の「QRSの形を作り替える」にあたり、脚ブロック・WPW・心室頻拍の回でも使える
3. **P'の形**：ふつうの P と見分けられるように、少し小さく、二相性にする（`p_amp` と `p_skew` を変える）
4. **2連発の3つめの R-R（0.65秒）を検算**：洞の P が伝わるか、不応期にかからないか
5. 最新の `ui.py` と `manual_reel.md` を Mac から取り直す（全カットに `ui.watermark()`）
6. 書き出し後、qc.py でつなぎ目を確認するときに **88.0秒 → 0.0秒** のループのつなぎ目も見る
