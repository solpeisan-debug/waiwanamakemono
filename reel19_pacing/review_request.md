## 各パターンの描き方（モデルの値）
| パターン | 画面のひとこと | 描き方 |
|---|---|---|
| ① 心房ペーシング | スパイク → P波 → 細いQRS | 心房スパイク → P波 → 自分の房室結節を通って細いQRS。60/分。スパイクからRまで 245ms |
| ② 心室ペーシング | スパイク → 幅の広いQRS（Tは逆向き） | 心室スパイク → 幅の広いQRS（約138ms、II誘導で下向き）、T波は上向き（QRSと逆向き）。P波なし。60/分 |
| ③ 心房・心室ペーシング | スパイクが2本：P波の前と、QRSの前 | 心房スパイク → P波 → 心室スパイク → 幅の広いQRS。スパイクの間隔（AV delay）190ms。60/分 |
| ④ P波に合わせるペーシング | 自分のP波のあと、QRSの前にだけスパイク | 自分の洞調律のP波（75/分）のあと 145ms で心室スパイク → 幅の広いQRS |
| ⑤ 自分の脈があれば休む | 自分の脈が出ているあいだは、スパイクが出ない | 自分の拍（75/分・スパイクなし）が3つ → 洞調律が止まり、最後の自分の拍から 1.0秒（下限の間隔）で心室ペーシング → 自分の拍が戻るとまた休む |
| ⑥ スパイクが小さい | スパイクが小さく、見えにくいことも（双極リード） | 心室ペーシングと同じで、スパイクの高さだけ 0.16mV（ほかは 1.0mV で描いている） |
| ⑦ 融合収縮 | スパイクと自分の脈がほぼ同時。QRSが中間の形 | 心室ペーシング2拍 → 自分の洞調律のP波のあと、ペーシングとほぼ同時に融合収縮（QRS 約123ms：自分 80ms とペーシング 138ms の間、スパイクは 0.75mV と短め）→ 自分の拍が続く |
| ⑧ 偽融合 | 自分のQRSにスパイクが重なるだけ。形は変わらない | ⑦と同じ並びで、融合収縮のかわりに偽融合：自分の細いQRSの頂点にスパイクが重なるだけで、形は変わらない |
| ⑨ ペーシング不全 | スパイクのあとに、QRSがない ＋赤で「→ すぐ報告」 | 心室ペーシング2拍 → スパイクだけでQRSがない → 1.0秒後のスパイクでまたQRS。QRSどうしの間隔 2.0秒 |
| ⑩ オーバーセンシング | スパイクが出ず、長く止まる ＋赤で「→ すぐ報告」 | 心室ペーシング2拍 → スパイクも出ない休み 2.4秒（下限の間隔 1.0秒より長い）→ ペーシングが戻る。筋電位などのノイズは描いていない |
| ⑪ アンダーセンシング | 自分の脈があるのに、スパイクが出る ＋赤で「→ すぐ報告」 | 自分の拍（75/分）があるのに、直前のRから 0.30秒（T波の頂点あたり）にスパイク。心室は不応期なのでQRSはつづかない |
| ⑫ ペースメーカー頻拍 | ペーシングのまま速い（上限の速さで続く） ＋赤で「→ すぐ報告」 | 心室ペーシングで 120/分（上限の速さの想定）。心室スパイクから 295ms に逆行性P波（ST部分） |

## とくに見てほしい点
1. ② 右室ペーシングのQRSを、II誘導で「幅の広い下向きのQRS・上向きのT」で描いた。代表の形として妥当か
2. ④ の名前「P波に合わせるペーシング」（心房センス・心室ペース）は、看護師向けの言い方として誤解がないか
3. ⑤「自分の脈が出ていれば、ペースメーカーは休みます」と、最後の自分の拍から下限の間隔（1.0秒）でペーシングが始まる描き方は正しいか（ヒステリシスは考えていない）
4. ⑦ 融合収縮・⑧ 偽融合の形（スパイクの位置・QRSの形）は妥当か
5. ⑨ ペーシング不全・⑩ オーバーセンシング・⑪ アンダーセンシングの描き方は、モニターで見たときの典型として妥当か。とくに ⑪ でスパイクがT波の上に出て、QRSがつづかない描き方
6. ⑫ ペースメーカー頻拍（120/分・逆行性P波）の描き方と、「上限の速さで続く」という言い方
7. 「すぐ報告」を ⑨〜⑫ に付けた範囲は妥当か。⑫ に「すぐ報告」は強すぎないか、ほかに付けるべきものはないか
8. 12パターンの選び方（マグネットモード、ランナウェイ・ペースメーカー、両室ペーシング（CRT）、ICD、センサー頻拍、リードのずれ は入れていない）
9. スマホの大きさで、スパイク（とくに ⑥ の小さいスパイク、⑪ のT波の上のスパイク）が読み取れるか。誤解を招く表現はないか
