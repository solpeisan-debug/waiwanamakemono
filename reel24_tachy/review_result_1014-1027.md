## 総評

医学的にまちがった波形や文言は、ほとんどない。②（LITFL の 150/分・camel hump の例そのもの）、⑥（下向きののこぎり・300/分・2:1で150/分）、
⑨（RP＞70ms・T波の始まりの切れこみ）、⑩（LITFL の「115/分・PR＜120ms・II誘導で下向きのP」の例そのもの）は、LITFL とよく合っている。

いちばん大きな課題は「その場で形が変わる」見せ方。とくに ③→④→⑤→⑥ の直接の変化は、「心房頻拍が多源性心房頻拍になり、心房細動になり、心房粗動になる」と読まれやすい。
LITFL には「多源性心房頻拍は、PAC の多発と心房粗動・心房細動のあいだの移行のリズムであることが多い」とあるので、
④→⑤・⑤→⑥ は**実際に起こる移行に見えてしまう**（意図しない「経過」を教えてしまう）。ここは推奨（優先度・高）。

要修正は1つ（最後の画面の「幅の狭い速い脈は、この10パターン」という言い切り）。あとは推奨。

## A. パターンごと

### 冒頭（1〜2ページ：問いかけ・フック）
- **判定：OK**
- 理由：「この10個、全部わかる？」と、止めた波形の変形（④⑤⑥⑦⑨）。フックは止めた画面で短く、名前も出ているので、経過と読まれる心配は小さい。2ページの「⑦ PSVT（房室結節リエントリー）」の名前と波形（182/分・P波なし）は合っている
- 直し方：なし

### ① 洞頻脈（3〜4ページ）
- **判定：OK**
- 理由：LITFL Sinus tachycardia「洞調律で心拍数＞100/分」。115/分・どの拍にもふつうのP・PR 162ms・QRS 86ms で正しい。原因の多くは二次性（痛み・脱水・低酸素・発熱・出血など、LITFL の原因の一覧）なので「→ まず患者さん」も合っている
- 直し方：なし

### ② 洞頻脈（P波がT波に重なる）（6ページ）
- **判定：OK（推奨1つ）**
- 理由：LITFL Sinus tachycardia の例が「150/分。P波が前のT波に隠れる」「とても速いと P波がT波に隠れ、camel hump（らくだのこぶ）に見える」。拡大すると T波の下り坂にこぶがあり、そのとおりに描けている
- 推奨：150/分前後でT波にこぶがあるのは、⑥の心房粗動（2:1、F波がT波に重なる）とも同じ見え方になる（LITFL Atrial flutter「130〜170/分の規則正しい幅の狭い頻拍なら粗動を疑う」）。キャプションに1行足すとよい
  - 足す文：「※150/分前後で規則正しく、T波にこぶがあるときは、P波が重なる洞頻脈・心房粗動（2:1）・PSVT を、12誘導で見分けます」
- 色の文字は「とくに見てほしい点 7」へ

### ③ 心房頻拍（10ページ）
- **判定：OK（推奨1つ）**
- 理由：LITFL Focal atrial tachycardia「P波の形と軸がふつうと違う（例：下壁誘導で下向き）」「同じ形のP」「P波のあいだの基線は平ら」。二相性のP'・130/分・1:1・規則正しい・基線が平らで、条件を満たす。
  LITFL の2つの例はどちらも II誘導で下向きなので、二相性は「代表」ではないが「ふつうと違う形」の一例としては許される。⑩と見分けるための選択として妥当
- 推奨：拡大すると P' は T波の終わりのすぐあとの小さな切れこみで、スマホでは ②（T波の下り坂のこぶ）と見分けにくい。P'の上向きの山を少し高く（0.13 → 0.16mV 前後）するか、P'と T波のあいだに少し平らなところができるよう T波の頂点を少し早くする
- 「とくに見てほしい点 10・15・18」も参照

### ④ 多源性心房頻拍（12ページ）
- **判定：OK**
- 理由：LITFL MAT「＞100/分（ふつう100〜150）」「PP・PR・RR がばらばらで不規則」「同じ誘導で3種類以上のP」「P波のあいだの基線は平ら」「1つの優位なペースメーカーがない」。
  4種類のP（ふつう・高くとがる 0.21mV・下向き −0.15mV・二相性）、PR 128〜199ms、平均117/分、どの形も2〜3拍ずつで偏りがない。拡大すると形の違いが読める
- 下向きのPのPRが 0.12秒以上で、LITFL PAC の「低い心房からの下向きP は PR≧120ms、120ms未満なら接合部」とも矛盾しない
- 直し方：なし

### ⑤ 心房細動（速い）（14ページ）
- **判定：OK（推奨1つ）**
- 理由：LITFL AF「不規則に不規則」「P波なし」「平らな基線がない」「細動波は細かい（＜0.5mm）か粗い（＞0.5mm）」「心室の速さは ~110〜160 が多く、＞100 で rapid ventricular response」。RR 0.34〜0.61秒・平均135/分で合っている
- 推奨：LITFL AF に「細動波がP波に似て見え、誤診のもとになる」とある。拡大すると、いくつかの拍で QRS の 0.09〜0.14秒前に丸いこぶがあり、P波に見えうる。「P波がなく」と教える場面なので、
  QRSの 0.08〜0.20秒前に1つだけ目立つ丸いこぶが来ないように、細動波の乱数（seed）を変えるか、周波数の下限を少し上げる（4.5 → 6Hz 前後）とよい。
  なお細動波の頻度（何Hz）は LITFL の AF ページには書かれていない（本文確認）。一般に 350〜600/分（約6〜10Hz）とされる（一般的な心電図の教科書の記載。本文未確認）
- 名前「心房細動（速い）」は看護師向けの言い方として可。正式には「頻脈性心房細動」（推奨・任意）

### ⑥ 心房粗動（2:1）（16ページ）
- **判定：OK（推奨1つ）**
- 理由：LITFL Atrial flutter「約300/分の規則正しい心房の活動」「平らな基線がない」「II・III・aVF で下向きののこぎり」「2:1 で 150/分」。拡大すると「ゆっくり下がって、すっと戻る」下向きののこぎりが 0.2秒ごとにあり、正しい
- 推奨：ひとこと「F波が、QRSとT波に隠れる」だが、絵では QRS のあいだにのこぎりがはっきり見える（見えること自体は教育上よい）。文と絵が少し食い違うので、画面の字を変える
  - 言い換え：「F波が、QRSとT波に重なる」または「F波の半分が、QRSとT波に重なる」
  - 台本「のこぎりの波が隠れる、心房粗動の2対1。」は録り直しが要るので、そのままでも可（「見えにくいことがある」という意味として通る）
- 「→ すぐ報告」：OK

### ⑦ PSVT（房室結節リエントリー）（20ページ）
- **判定：OK（推奨1つ）**
- 理由：LITFL SVT「AVNRT は 140〜280/分で規則正しい」「slow-fast型（80〜90%）は P波が QRS に埋もれるか、II・III・aVF の偽S波」。182/分・P波なし・QRSの終わりの小さな偽S波で正しい
- 推奨：名前の言い方。「房室結節リエントリー」は仕組みの名前で、不整脈の名前としては「房室結節リエントリー性頻拍（AVNRT）」。キャプションはすでに「房室結節リエントリー性頻拍（⑦）」と書いているので、画面もそろえる
  - 言い換え（画面の大きい名前）：「PSVT（房室結節リエントリー性頻拍）」。長くて入らないなら「PSVT（AVNRT）」、枠の小さい名前も同じに
- 「とくに見てほしい点 11」も参照

### ⑧ 始まり方：PSVTと洞頻脈（24〜26ページ）
- **判定：OK（推奨2つ）**
- 理由：LITFL SVT「Paroxysmal SVT は突然始まり突然止まる。AVNRT・AVRT のような房室結節を含むリエントリーに特徴的」「slow-fast AVNRT は、速い道がまだ不応期のときに来た PAC が遅い道を下りて始まる」。
  PAC（P'→R 0.22秒）→ 170/分 → 突然止まり 0.8秒あけて洞調律、という流れは正しい。
  コードで確かめると、PAC の P' は直前の洞調律の R から 0.14秒（T波の上り坂）に乗っていて、画面ではほとんど見えない。PRが長いことも見た目ではわからないが、台本で言っていないので問題ない
- 「少しずつは洞頻脈」：LITFL Sinus tachycardia のページには「徐々に始まる・終わる」の記載はない（本文確認）。一般的な記載（2015 ACC/AHA/HRS 成人SVTガイドライン。本文未確認）。
  ひとこと・台本とも「洞頻脈が多い」と言い切っていないので可
- 推奨1：色の文字「→ 数字を見る」（「とくに見てほしい点 7・8」参照）
- 推奨2：「突然始まる」のは PSVT だけではない（LITFL SVT：洞結節リエントリー性頻拍も突然始まり突然止まる。心房細動・心房粗動・心房頻拍も突然始まりうる）。
  画面の「突然はPSVT、少しずつは洞頻脈が多い」は「多い」が両方にかかるように読めるので可。台本「突然始まり、突然止まるのはPSVT。」は言い切りだが、規則正しい幅の狭い頻拍の文脈なので許容。録り直すなら「突然始まり、突然止まるなら、PSVTを考える。」

### ⑨ 房室回帰性頻拍（順方向性）（30ページ）
- **判定：OK**
- 理由：LITFL AVRT「順方向性は 200〜300/分」「逆行性P波はたいてい見え、RP＞70ms」「T波の始まりの小さな切れこみとして見える」「不安定なら緊急の電気的除細動（DC cardioversion）」。
  200/分・RP 112ms（QRSの終わりから26ms）・下向きの切れこみで、LITFL の見え方と合っている。拡大すると QRS のあと「S → 小さな山 → 下向きの切れこみ → T波」で、P'は読める
- 直し方：なし（「とくに見てほしい点 12・18」）

### ⑩ 接合部頻拍（34ページ）
- **判定：OK（推奨1つ）**
- 理由：LITFL Accelerated Junctional Rhythm「接合部の頻拍は＞100/分」「逆行性Pは QRS の前・中・後のどこにも出て、下壁誘導で下向き」。例1が「115/分、II・III・aVF で下向きの逆行性P、PR＜120ms は心房でなく接合部」で、⑩はこの例どおり
- 推奨：ヒント・ひとこと・台本が「QRSの直前に逆向きのP」なので、「接合部頻拍ならいつも直前にPが見える」と覚えられやすい。キャプションに1行足す
  - 足す文：「※接合部頻拍の逆向きのP波は、QRSの直前のほか、QRSに隠れたり、QRSのあとに出たりもします」
- 「→ すぐ報告」：OK（LITFL の原因：ジギタリス中毒・心筋虚血・心筋炎・心臓の手術のあと・β刺激薬。どれも医師に知らせたい）

## B. とくに見てほしい点

### 1. その場で形が変わる見せ方（直接変わるつなぎ目）
| つなぎ目 | 判定 | 理由 | 直し方 |
|---|---|---|---|
| ①→②（115 → 150/分、P波がT波の下り坂へ） | **OK** | 同じ洞調律の速さが上がるのは、実際に少しずつ起こること。PR も 162 → 132ms と短くなり、生理的。「同じ洞頻脈が速くなる」という見せ方として妥当 | なし |
| ③→④（心房頻拍 → 多源性心房頻拍） | **推奨（高）** | 「心房頻拍が多源性心房頻拍になる」は、ふつうに教える経過ではない。直接変えると経過に見える | ①（または下の案の中立の形）を通す |
| ④→⑤（多源性心房頻拍 → 心房細動） | **推奨（高）** | LITFL MAT「多源性心房頻拍は、PAC の多発と心房粗動・心房細動のあいだの移行のリズムであることが多い」。実際に起こる移行なので、直接変えると「この順に悪くなる」と教えてしまう。この回で教えたいことではない | 中立の形を通す |
| ⑤→⑥（心房細動 → 心房粗動） | **推奨（高）** | 心房細動と心房粗動は行き来することがあり（LITFL AF「抗凝固の指針は、心房細動になりやすいので心房粗動も含む」）、「細動がまとまって粗動になる」という経過に読まれる | 中立の形を通す |

まとめ：③→④→⑤→⑥ は4つ続けて同じ色（オレンジ）で直接変わるので、「1人の患者さんの中で、この順に移っていく」と読まれる可能性は高い。
①→② だけを直接にして、ほかのつなぎ目はすべて中立の形を通すように統一するのがよい。

### 2. ①の形を通すつなぎ目
- **判定：推奨**
- 理由：①自体が頻脈のパターンなので、「⑥心房粗動 → 洞頻脈 → ⑦PSVT」のような経過に読まれる余地がある。ただし、形が変わるあいだは帯の色が緑（①の水色ではない）になり、名前もカウンターも消えているので、
  ①の紹介の場面とは区別がつく。誤解の危険は中くらい
- 直し方（どれか、または組み合わせ）
  1. いちばん効く：形が変わるあいだ、帯の上（名前の行の位置）に小さく「▶ 次の例」と出す。直接のつなぎ目（①→②を除く）にも同じ字を出す
  2. 通す形を、①（115/分の頻脈）ではなく、75/分前後のふつうの洞調律にする。「ふつうの心電図にもどってから、次の例」という読み方になり、「頻脈が洞頻脈に変わった」という読み方を避けられる。
     最後の画面も同じ形にもどせば、冒頭の帯（①）とのつながりだけ①にもどす（⑩→最後の部分だけ①）
  3. 形が変わるあいだ、帯を少し暗く（不透明度 50〜60%）して、「紹介中ではない」ことを見た目でも示す

### 3. 心拍数カウンター（名前の行のあいだだけ表示・値）
- **判定：OK**
- 理由：形が変わるあいだは出さないので、混ざった形の心拍数は出ていない。表の値はすべてモデルの RR と合う（①115、②150、③130、⑥150、⑦182、⑨200、⑩115）。
  ④ 102〜136/分はどれも＞100（LITFL MAT「＞100/分」）。⑤ 98〜176/分は、AF の RR 0.34〜0.61秒と合い、平均135/分は LITFL の ~110〜160 に入る。
  ⑤で 98 が一瞬出るが、「1拍ごとの値（モニターは平均）」が出ているので可。
  ⑧の 90 → 167（PAC の拍、RR 0.36秒）→ 170 ×4 → 75（0.8秒あく）→ 90〜135〜90 も計算どおり
- 直し方：なし

### 4. コピーが枠へ飛ぶあいだに、帯が変わり始める
- **判定：推奨**
