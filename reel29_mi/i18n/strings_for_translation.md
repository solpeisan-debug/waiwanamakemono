# 第29弾 翻訳用の表（i18n/ja.json のキー）

- 訳したら `i18n/zh-TW.json`・`i18n/en.json` の同じキーに入れる（`_meta` はそのまま）。
- 「最大の幅」は、その字の大きさでの横幅の上限（1080×1920 の画面の px）。こえると自動で縮むか、はみ出す。訳したら `REEL29_LANG=en python3 make_reel29.py --check` で確かめる（表に抜けたキー・字体にない字・はみ出し・重なりが出る）。
- 字体：zh-TW は Noto Sans TC、en は Noto Sans。**Noto Sans（英語）には ①〜⑥・→・↑↓←・〜・＝・（）・全角の記号が入っていない**ので、英語では 1. / -> / ~ / = / ( ) など半角の記号にする（`p1_no` など番号も）。
- 誘導名（I・aVL・V1〜V9・V4R）、LAD・LCx・RCA はそのまま。
- 字幕の長さは、言語ごとの読む速さ（`_meta.read_cps`：zh-TW 1秒に5字、en 1秒に2.8語）で決まる。訳が長いと、その場面が長くなる。
- 電極の色：ja・zh-TW は IEC、en は AHA（`_meta.electrode_colors`）。
- ナレーション：`vo_*` の文を訳して録り、`out/vo/lines_zh-TW/`・`out/vo/lines_en/` に同じ名前（n00.mp3 など、1.2倍・前後の無音を切る）で置く。`vo_p1`〜`vo_p6` は台本の文（録り直しで読み方だけ変えたもの）、`vo_m1` は録音した文が手元にないので要確認。
