## 1. 共通の決まり
- **返事・画面・台本・キャプションは日本語**。視聴者に「第◯弾」は見せない（管理番号）
- **医学的な根拠は LITFL が第一**（https://litfl.com/ 。`curl -sL -A "Mozilla/5.0" URL` で本文が取れるページが多い。WebFetch が 403 のときは curl）。
  LITFL 以外を使うときは、出典を確認して名前を書く。分からないことは「レビューで確認」と依頼文に書く（作り話をしない）
- モニター（**II誘導**）・実際の速さ（25mm/秒）を想定。画面とキャプションに「数値はこの波形での一例」
- **ナレーションで「すぐ報告」と言わない**（画面の色の文字とキャプションで伝える）
- 台本は **1パターン1文（声で3〜4秒）**。冒頭の一文は「〈テーマ〉。まず覚えたいのは、この12パターン。」の形。最後は「まとめの一文」＋「保存して、見返してね」。
  くわしい説明は画面のひとこと（`one`）とキャプションにまかせる（第21弾の「ぎゅっと版」と同じ考え方）
- 録音は後でユーザーが ElevenLabs（Ren – Smooth & Soothing）で行う。いまは**録音前の版**（区間の長さは仮）を作る
- **キャプション**は第21弾 `reel21_arrest/caption.txt` の短い形にそろえる。「※参考」の下・ハッシュタグの上に、
  リポジトリ直下 `caption_template.txt` の3行を**そのまま**入れる（目印の文は残さない）
- チャットで送るファイル名：`第NN弾_テーマ_中身_MMDD-HHMM.拡張子`（日本時間 `TZ=Asia/Tokyo date +%m%d-%H%M`）。
  各回の `out/send/` にコピーする（元の名前は変えない）。**チャットへの送信と git commit はオーケストレーター（親）が行う**ので、エージェントはしない

## 2. リール（12パターン）の作り方 ― 第21弾をひな形にする
ひな形：`reel21_arrest/`（`make_reel21.py`・`align_vo.py`・`make_review_pdf.py`・`narration.md`・`caption.txt`・`fonts/`）。
新しい回のフォルダ（例 `reel24_tachy/`）にコピーして、ファイル名・番号・中身を置きかえる（`fonts/` もコピー）。

`make_reelNN.py` で置きかえるところ：
- 先頭の説明（docstring）・配置の説明
- 色（`C_...`）、`KINDS`（拍の種類。必要なら QRS や T の形の関数を足す）、連続した波形の関数（`art_...`・`gain_...`）
- `PATTERNS`（12個。`no, name, col, hint, one, tag, ev, L, art, gain, hl`）
  - `one`（画面のひとこと）は短く。ひとこと＋色の文字の幅は `ONE_W = 760`px 以内（入らないと字が小さくなる）。`--check` で確かめる
  - `hint`（ミニ波形の枠のヒント）は 8字くらいまで
- `TAGS`（ひとことのうしろの色の文字。その回の意味に合わせて作る。例：「→ すぐ報告」「→ 正常の範囲」「→ 12誘導で確認」）
- `SEG_D`（各パターンの区間の長さ）：**仮の値**。台本の各文の長さの見込み（6字/秒くらい）＋0.75秒以上で、拍の並びがくずれない位置で切る。3.44秒以上。
  全体で 60〜70秒くらいになるように（第21弾は 65.3秒）
- `T_TITLE`（冒頭の一文が入る長さ。仮で 4.9）、`HOOK`（冒頭3秒で変形して見せる5パターン）、`HEADER`（見出し：テーマ＋「12」＋「パターン」）、
  最後の文（例「急変のまえに、この12パターン」）、`THUMB_VIEW`/`THUMB_DESC`（サムネイル）、`--check` の検算の print
- 使わなくなった関数・定数・古いコメントは消す

`align_vo.py`：`LINES`（冒頭＋①〜⑫＋まとめ＋保存 = 15文。声のかたまり番号は仮で1文1つ）、`TEXT`、出力ファイル名。
`make_review_pdf.py`：`SRC`（出典）、`describe()`（各パターンの描き方をモデルの値から）、依頼文の概要・「とくに見てほしい点」、ファイル名。
`narration.md`：読み上げ用の台本・言い回しの注意（LITFL の該当文を英語のまま引用）・声の指定。

## 3. 作る順番（各回）
1. 医学の裏取り（LITFL）→ 12パターンを決める（他の回と重ならないように。下の「担当」を見る）
2. `make_reelNN.py` を作り、`python3 make_reelNN.py --check` で間隔・幅を検算（つなぎ目の拍の間隔がおかしくないか）
3. `--still` で数コマ、`--thumb` でサムネイルを出して**自分の目で見る**（Read で画像を開く）
4. 台本・`align_vo.py`・キャプション・`make_review_pdf.py` を作り、`python3 make_review_pdf.py` で
   `out/review_reelNN_frames.pdf`（等倍・1ページ1コマ）と `review_request.md` を作る
5. **ここで一度止めて報告**（検査役のチェックを受ける）。指摘を直したあとで、
6. 無音の確認用の映像を書き出す：`python3 make_reelNN.py --jobs 2`（CPU は4つしかないので **--jobs 2**）
7. `out/send/` に、依頼文・キャプション・フレーム等倍PDF・サムネイル・台本・映像（無音）を名前を付けてコピー

## 4. 画面のバランス（検査役が見るところ。最初から守る）
- 画面 1080×1920。文字は左右 **72px 以上**内側、上は **250px より下**、下は **1600px より上**（下はリールの説明文がかぶる）
- 右下（x 900 以上・y 1100〜1600）はリールのボタンがかかる。大事な文字を置かない
- 見出し・ブロックの間の余白は上下でそろえる（片寄らない）。枠の中の波形は、枠の上の字と枠の下の間のまん中
- 字が枠からはみ出さない・切れない・重ならない。小さい字でも 18px 以上
- 透かし `@nurse_polarbearden` はサムネイル以外の全コマ。ほかの字と重ねない
