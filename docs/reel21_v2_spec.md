## 見る場所（5か所）と次の対応（ユーザーと決めた文言）

| 見る場所 | 波形 | 次の対応 |
|---|---|---|
| ① PとQRSのつながり | モビッツII型／完全房室ブロック | → 意識・血圧・胸痛・息苦しさ等確認。要すればペーシングのパッド着用 |
| ② QRSの幅と形 | ショートラン | → 症状を見て、12誘導。QT、K・Mgなどを確認 |
| 〃 | 単形性VT | → 脈あり：意識・血圧・胸痛・息苦しさ等確認。要すればパッド着用 ／ → 脈なしなら人を呼ぶ。CPR＋電気ショック |
| 〃 | 多形性VT | → 脈なし：CPR＋電気ショック ／ → 脈あり：人を呼び、要すればパッド着用（続けば脈があってもショック） |
| 〃 | トルサード | → 脈なし：CPR＋電気ショック ／ → 止まっても12誘導。QT、K・Mgなどを確認 |
| ③ T波の上 | R on T | → 12誘導。QT、K・Mgなどを確認。除細動器を近くに |
| ④ QRSがない | 粗いVF | → 反応を確認し、人を呼んでCPR＋電気ショック |
| 〃 | 細かいVF | → CPR＋電気ショック（細かくてもVFならショック） |
| 〃 | 心静止 | → 人を呼び、すぐCPR（ショックはしない）。並行して電極外れ・感度を確認 |
| ⑤ 波形では分からない | PEA（ふつうに見える）／PEA（遅く幅広い） | → 脈なしなら人を呼ぶ。すぐCPR（ショックはしない）、原因（4H4T）を確認 |
