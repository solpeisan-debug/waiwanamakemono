## 4. 波形の作り方（関数・パターンの定義・つなぎ目・特別な見せ方）

基本の関数（`src/ecg.py`）：
- 【技術】`NORMAL` …1拍の形の辞書（p_amp, p_dur, pr, q/r/s の高さと幅, st, t_amp, t_dur など）。`ecg._upd(基, **変更)` で形を変える。
- 【技術】`beat(ts, P)` …R頂点を0秒とした1拍の電位。`beats_at(xs_mm, P, rs, t0_mm)` …R の時刻のリストに拍を並べる。`waves_at(xs_mm, P, ps, rs, …)` …P と QRS を別々の位置に置く（房室ブロック用）。`p_center(P)` …R から P の中心までの秒。`fwave(xs_mm, amp, t0_mm)` …粗動のノコギリ。
- 【技術】`render(w, h, ppm, P, t0_mm, y0, col, x0_mm, ss, vfun, …)` …方眼と波形を描く。`vfun` に「mm → mV」の関数を渡すと、どんな並びでも描ける。
- 【技術】座標は「世界の mm」。`T0_MM` が拍0の R の位置。カメラは `dict(ppm, x0, y0)`。カメラ同士は `lerp_cam(a, b, u)` でなめらかに動かす。

- 【技術】調べ方：LITFL ECG Library、Medscape、StatPearls を先に見る。画面の数値はモデル波形から計算する（手打ちしない）。
- 【この回だけ】心房粗動：心房はおよそ300/分、F-F 200ms は教える上での単純化として正しい。伝導比が一定なら R-R は F-F の倍数。2:1 で 150/分の規則正しい頻拍に見える（150 で整っていたら粗動を疑う）。伝導比が変わると細動に似る。1:1 伝導の原因に Ic群などの抗不整脈薬。抗凝固は細動と同じ考え方。出典：キャプションに「LITFL ECG Library（Atrial Flutter）」（`src/script/caption_flutter.txt`）。
- 【この回だけ】ウェンケバッハ：PR は延びるが**延び幅は減る**、RR は短くなる、休止は最短RRの2倍より短い、房室結節、症状がなければ治療しないことが多い。モビッツII：PR は一定、ヒス・プルキンエで急に途切れる、QRS が広いことが多い、ペースメーカーの適応、アトロピンで悪くなることがある。2:1 はどちらか決められない。出典：キャプションに「LITFL ECG Library（AV block: 2nd degree, Mobitz I／Mobitz II）」「Medscape（Second-Degree Atrioventricular Block）」（`src/script/caption_wenckebach.txt` `caption_mobitz2.txt`）。調べるときは StatPearls も見たが、キャプションには載せていない。
- 【この回だけ】完全房室ブロック：出典はキャプションに「LITFL ECG Library（AV block: 3rd degree / Accelerated Junctional Rhythm）」（`src/script/caption_avblock.txt`）。
- 【この回だけ】右脚ブロック（2026-09-18 確認）：QRS>120ms、V1〜3 で rSR′（M字）、I・V5-6 で幅広い S、V1〜3 の ST 低下・T 陰転。出典：https://litfl.com/right-bundle-branch-block-rbbb-ecg-library/
- 【この回だけ】左脚ブロック（2026-09-18 確認）：QRS≧120ms、V1 は幅広い QS か rS、I・aVL・V5-6 は幅広い一峰性 R で Q がない。新しい左脚ブロック＝すぐ STEMI ではなく、Sgarbossa 基準で見る。出典：https://litfl.com/left-bundle-branch-block-lbbb-ecg-library/
- 【この回だけ】WPW（2026-09-18 確認）：PR<120ms、デルタ波、QRS>110ms、ST-T は QRS と逆向き。出典：https://litfl.com/pre-excitation-syndromes-ecg-library/
- 【この回だけ】しくみ第4話のモデルで実測した値：正常 89ms、右脚 132ms、左脚 136ms、PVC 170ms、WPW 136ms（PR 100ms）。
