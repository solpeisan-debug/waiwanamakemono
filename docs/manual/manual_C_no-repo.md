## 4. 波形の作り方（関数・パターンの定義・つなぎ目・特別な見せ方）

### 土台 `src/ecg.py`
- 【技術】`ecg.beat(t, P)`：R頂点を0秒とした時刻 → 電位(mV)。P・Q・R・S・T・U を「山」（`_bump`）の足し算で作る
- 【技術】形はパラメータの辞書 `P`。基準は `ecg.NORMAL`。差分だけ `ecg._upd(ecg.NORMAL, t_amp=0.95)` のように書く
  - 追加の部品：`delta_amp`（デルタ波）、`r2_amp`（脚ブロックの R'）、`u_amp`、`st_dep`・`st_elev`、`sine`
- 【技術】並べる：`beats_at`（R の位置に拍を置く）、`waves_at`（P と QRS を別々に置く＝房室ブロック）、`fwave`（細動波）
- 【技術】描く：`ecg.render(w, h, ppm, P, t0_mm, y0, col, x0_mm, ss, vfun)`。横は mm の世界座標
- 【技術】検算：`ecg.measure(P)`（P・PR・QRS・QT を ms で返す）
  - 【注意】ST がずれている波形（低K・ST上昇）や、ずっと続く波（f波）では、QRS が実際より長く出る。そのときは `q_dur+r_dur+s_dur` で確かめる

### 各回の波形 `src/*_core.py`
| ファイル | 中身 |
|---|---|
| `af_core.py` | 心房細動：R-R の並びは手で決めた（`RR_FWD`）、f波 0.065mV |
| `fl_core.py` | 心房粗動：F-F 0.20秒、`saw()`（ゆっくり下がって急に上がる）、4:1・2:1 |
| `ec_core.py` | PAC・PVC：`build(kind)` が P・R の位置と形を返す |
| `wb_core.py` | ウェンケバッハ（PR 0.16→0.32→0.42→脱落）・モビッツII（PR 0.18 一定） |

  - `src/mkpdf.py 動画.mp4 出力.pdf 間隔秒` で作れる。PSVT は場面ごとに秒を選んで37コマ（`PSVT_レビュー用コマ_1001.pdf`）
  - 【注意】縮小した1枚シートは読み違えられる（aVF を VF と読まれた。`manual_reel.md` §7）
- 【決まり】これまではユーザーが Gemini（Pro／Deep Think）に手で頼んでいた。**今後は Claude が、ユーザーのクロームで Gemini に送って結果を回収する**（2026-10-06）
  - 【決まり】Gemini のチャット名は「アカウント＋第何弾＋テーマ」。例 `【みんなの看護】第10弾 PSVT｜専門医チェック`（日付の記録なし。メモリ）
  - 【未確定】このスレッドでは、まだ実際に Claude から送ったことはない
- 【決まり】返ってきた指摘は、そのまま直さない。2つ以上の情報源で裏取りして「直す／言い過ぎ／採用しない」に分けて見せる
  - 例：「プロカインアミド静注は販売中止」は誤り（止まったのは錠剤）（`引き継ぎ_02.md`）
  - 例：「喘息に ATP は禁忌」は言い過ぎ → 「原則使わない」にした（PSVT 2026-10-01。§8）
- 【技術】記録は `src/script/review_*.md`（例 `review_mobitz2.md`：反映した指摘・しなかった指摘と理由）
- 【注意】レビューの文章に、AI のコード実行のあとや絵文字が混ざっていることがある。人の専門医チェックの代わりにはしない（PSVT 2026-10-01）

## 8. 医学の根拠

- 【技術】調べる先：LITFL ECG Library、StatPearls、MSDマニュアル、Medscape、添付文書（KEGG・PMDA）、ガイドライン。1つで決めない
- 【決まり】日本の現場の呼び方にそろえる：頻拍を止める薬は ATP（アデホス）（`引き継ぎ_02.md`）

### PSVT（2026-09-25〜10-02 に確かめたこと）
- 【この回だけ】心拍数 140〜280回/分（LITFL）。120〜250回/分とする解説もある（ECG book）→ 画面は「目安」と書く
- 【この回だけ】ATP は日本の添付文書では PSVT が効能に入っていない（適応外で広く使われている）。禁忌は「脳出血直後」だけ（`src/script/daihon_psvt.md`）
- 【この回だけ】喘息：日本の添付文書には書いていない。米国の添付文書は「喘息など気管支れん縮のある人では避ける」、日本麻酔科学会の麻酔薬使用ガイドライン第4版は ATP の禁忌に「喘息等の気管支攣縮性肺疾患」→ 画面と声を「喘息がある人には 原則使わない」にした（2026-10-01）
- 【この回だけ】量：初回 10mg を急速静注して生食20mL で後押し、効かなければ 20mg、という解説が多い（沖縄県医師会報、レジドクター）。コメント返信では「医師の指示と施設の決まりに従って」と添えた（2026-10-02）
- 【この回だけ】修正バルサルバ（REVERT、Lancet 2015）、ATP は注射の前から記録（EMCrit）
- 【この回だけ】広い QRS の規則正しい頻拍は心室頻拍を疑う → 画面に声なしで1行足した（2026-10-01）

### WPW（このスレッドの前半）
- 【この回だけ】心房細動は WPW の約20%、心房粗動は約7%。使ってはいけない薬：ATP・ベラパミル・ジルチアゼム・β遮断薬・ジギタリス・アミオダロン静注（`src/script/caption_wpw.txt`）

### ほかの回
- 【この回だけ】モビッツII の原因から β遮断薬を外した（LITFL と StatPearls で割れた。`src/script/review_mobitz2.md`）

## 10. はまりどころ・失敗と対策

- 【注意】**台帳の番号と投稿の順番がちがう**。台帳では PSVT＝第10弾・WPW＝第14弾だが、投稿の順番はちがう。ドライブのフォルダは台帳の番号で付けた（2026-10-07）
- 【注意】PIL は文字の透明度を混ぜない。薄くするなら `ui.fcol(色, a)`（`manual_reel.md` §5）
- 【注意】RGBA の画像に半透明の図形を直接描くと穴があく → 別のレイヤーに描いて `alpha_composite`（PSVT の回転ドア・QRS の帯）
- 【注意】方眼と波形がずれて「横線がたくさん入る」→ 心電図の帯は画面の高さいっぱいで描き、方眼と同じ座標にする（PSVT 2026-10-01）
- 【注意】背景を抜くときに、きつすぎる条件で絵が黒くなった → 白に近く色の薄いところだけ抜く（回転ドアの絵）
- 【注意】場面の重ねで文字が二重に見えた → 切りかわる0.5秒前に消す、`keep()` で場面の中だけ出す
- 【注意】`pkill -f` の条件が自分のシェアにも当たり、コマンドごと止まった → プロセス番号を `ps` で調べて止める
- 【注意】クラウドの作業場は消える。途中で消えたこともある（2026-10-15）。終わったら毎回 Mac に保存する
- 【注意】Mac とのつながりがよく切れる。切れたら少し待つ。道具を探し直して読み込む
- 【注意】古いスナップショット（`src/_src_snapshot.tgz`）から戻すと古い版になる（`引き継ぎ_02.md` §2）
- 【注意】AI のレビューをそのまま信じない（§7）
- 【注意】字数を数えるとき `wc -m` はロケールによってバイト数になる → Python の `len()` で数える
