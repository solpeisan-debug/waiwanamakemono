## 4. 波形の作り方
- 【技術】拍の部品は「山」（ガウス・非対称の山）の足し算。基本の形の辞書から差分だけ変える（`ecg.NORMAL`＋`_upd()` [B][C]、`KINDS`/`PATTERNS` [A]、`bump/abump` [D]）
- 【技術】T波は左右非対称（上りが長く下りが短い）[D]
- 【技術】検算：`ecg.measure(P)` [C]、`--check` [A]、`qc*.py` [D]。【注意】ST がずれた波形や f波があると QRS が長く測れる → 部品の長さで確かめる [C]
- 【技術】**拍の位置は位相を積み上げて決める**（RR が変わっても拍が跳ばない・消えない）[A][D]
- 【技術】**その場で形を変える**：時刻だけで決まる段階 s(t)、形は数値（高さ・位置・幅・PR・QRS幅）を補間。波形どうしを重ねて混ぜると山が2つに割れる [A][D]。変える時間 0.8〜2.0秒 [D]、1.0秒 [A]
- 【決まり】（A 2026-10-14）その場で直接変えるのは**同じ病態の中だけ**。別の病態へは、うすい灰色の「ふつうの洞調律」を一瞬通し「▶ 次の例」と出す（「ある不整脈が別の不整脈に移る」と誤解させないため。AI専門医の指摘）[A]
- 【技術】一時停止：説明中は流れを止める。止めた瞬間にR頂上が中央に来るよう位相をずらす [C][D]。密集した速い波形は止めると目が疲れない [A]
- 【技術】モニター風：「いま」より右はまだ描かない・光の点 [C]、画面中央を「いま」として毎コマ描き直す [D]
- 【技術】カメラ：世界の mm 座標＋`lerp_cam()`、次のカットの cam0＝前の cam1 [B]。拡大は方眼も一緒に [A][D]
- 【技術】心拍数カウンター「♥ ◯/分」（拍で光る・1拍ごとの値、不規則なら注記）[A]、モニター風の HR 表示 [D]
- 【技術】英字ラベル（P・Q・R・S・T・U）：縁どり付きの文字、拍と一緒に流す [A][C]
- 【技術】心臓インセット（`src/heart_inset.py`）・心臓の切り口の絵（Flow 製）と組み合わせる型 [B][C][D]
- 【注意】乱数で作った細動波が QRS 直前で P波に似たこぶになる → 種を変える [A]
