### 10-4. 血流（液体の見せ方）。ユーザーに没にされた順
- 【注意】点々（粒）→「変」。液体にする。
- 【注意】流体計算＋模様（`flow/cfd/render_cfd2.py`）→「色の付いた煙」。
- 【注意】管の表面にも液を描いた →「表面には通っていない」。液は断面の部屋だけ、管は矢印（`flow/cfd/arrows.py`）。
- 【注意】不透明でつやのある液（`flow/cfd/render_liq.py`）→「絵の具みたいでドロドロ」（2026-10-09）。
- 【注意】薄く透ける液（`flow/cfd/render_thin2.py`）→「液体だとわかりづらい」（2026-10-10）。
- 【注意】AI動画（Flow・Veo 3.1 Fast・最初と最後のコマに同じ絵・2本＝20クレジット）→「下から溜まっていくようにしか見えない」（2026-10-10）。AIは、部屋が空から満ちて引く動きを作った。本物の部屋はいつも血で満ちているので、教材として誤解を招く。
- 【技術】今の版：高さのある液面を光線で計算（屈折・深さで色・照明の映り込み）＋光る流れの線（`flow/cfd/render3d.py` ほか）。「流れは良くなった」（2026-10-10）。
- 【注意】大きなバグ：心房と心室の部屋（手でなぞった多角形）が離れていて、流体計算で房室弁を通る流れが出ていなかった。弁の輪（ring）を足してつないだ（`flow/cfd/cfd.py`、2026-10-10）。つないだあと、弁が閉じているときに漏れがないかを、つながった領域の数で確かめた。
- 【注意】液のふちが直線になる・大動脈にはみ出す・穴があく → 部屋の多角形を広げ、絵の暗い所だけに液を残す。はみ出す所は手で除く（`flow/cfd/render_thin2.py` の REG・_AOX・FILL）。
- 【注意】さざ波を float16 で保存すると、液面に階段の模様が出る → 平らな深さとの差をぼかしてから強める（`flow/cfd/render3d.py`）。
- 【注意】流れの線：短い跡は「雨」「ひっかき傷」に見える → 短い跡は描かない、尾を長く、赤い部屋は本数半分・うすいピンク（`flow/cfd/lines_draw.py`）。
- 【注意】心房→心室へ流れこむ時期は流れが遅く、線がほとんど見えない → 線の動きだけ最大3倍に速めた（`flow/cfd/lines_export.py`）。実際の速さの比べ合いではない。
- 【注意】弁：白い線は意味が伝わらない／名札が一瞬で消える → 扉で描き、名札は出しっぱなし（`flow/valve_viz.py`）。大動脈弁と僧帽弁が1本の棒に見えた → 僧帽弁の付け根を26pxずらし、大動脈弁を0.85倍、開いた房室弁は0.85倍に短く。
