## 1. なぜ「シームレス」がこの回に合うか

ウェンケバッハは**同じ周期を繰り返すリズム**（ここでは P4つ・QRS3つで1周期）。
だから、波形を1本の長い帯（世界座標）として置き、カメラが紙送りと同じ向きに流れ続ければ、

1. **カメラが切れない**（シリーズの決めごと4：`cam0 = 前のカットの cam1`）
2. **最後のコマ = 最初のコマ**：尺をちょうど 27 周期にすると、終わりのカメラは始まりのカメラから 27周期ぶん（27 × 80mm）右にずれるだけ。周期が 80mm で方眼（5mm）の倍数なので、**波形も方眼も同じ絵**になる → リピートで継ぎ目が消える
3. **平均速度 = 25mm/秒**：最初と最後が 2160mm 離れていて、それを 86.4秒で進む。つまりカメラは平均して**本物のモニターと同じ速さ**で流れている。寄り・引きは各カットで足し引きするだけ

実装の決まり（提案）：

```python
ctr_mm(t) = HOOK_CTR + 25*t + off(t)   # off(t) はカットごとの寄り道。t=0 と t=86.4 で 0
ppm(t)    = カットごとに補間。t=0 と t=86.4 で HOOK の ppm
```

- 最後のカットの `cam1` は `wk_core.LOOP_END`（= HOOK を 27周期ずらしたもの）にする
- 保存カードは波形の上に**重ねて**出し、最後の 0.6秒でフェードアウトして素の波形に戻す（カードの文字にも OUTF を掛ける）
- 効果音：QRSごとにモニター音「ピッ」。**抜けた拍だけ鳴らない**。音も3.2秒周期なので、ループしても拍の途中で切れない
- ナレーションの最後の一言は 85.0秒までに終える（つなぎ目は拍の音だけにする）

### 落とし穴カード（「例外」と「落とし穴」を分けて言う）

1. **2:1 ブロックは、どっちか決められない**（落とし穴）
   P2つにQRS1つだと、伸びるPRを2拍続けて見られない。ウェンケバッハとモビッツIIを心電図1本では見分けられないので「2:1房室ブロック」と呼び、報告する
2. **きれいに伸びないことが多い**（例外）
   伸び幅がそろわない、最後に少し短くなる（非典型ウェンケバッハ）。**抜ける直前と直後のPRを比べる**のがいちばん確実
3. **PRが伸びずに、突然抜けたら別物**（落とし穴）
   それはモビッツII。QRSが広いときも要注意。完全房室ブロックへ進むことがあるので、すぐ報告

### まとめカード（3ブロック）

- 見出し：**2度房室ブロック ウェンケバッハ型**
- 枠の中：
  - PRが1拍ごとに伸びる（伸び幅はだんだん小さく）
  - Pはあるのに、QRSが1つ抜ける
  - 抜けたあと、PRはいちばん短く戻る
- 保存の一言：**伸びて、伸びて、抜ける。保存して、見返してね**

## 3. 波形モデル（`wk_core.py`）の数値

P-P 800ms（心房 75/分）、4:3 伝導。PR = 180 → 280 → 330ms、4つめのPで抜ける。

| 項目 | 値 | 確認すること |
|---|---|---|
| PRの伸び幅 | +100 → +50ms | だんだん小さくなる（典型） |
| R-R | 900 → 850 → **1450**ms | 抜けるまでだんだん短くなる |
| 抜けを含むR-R | 1450ms | 2 × P-P（1600）より短い。2 × 最短R-R（1700）より短い |
| 心室の平均 | 3拍 / 3.2秒 ≒ 56/分 | 「この波形での一例」 |
| 1周期 | 3.2秒 = 96コマ = 80mm | 方眼5mmの倍数 → ループで方眼もそろう |
| 全体 | 27周期 = 86.4秒 = 2592コマ | 85〜90秒の範囲 |

`python3 wk_core.py` で上の表を print する（手計算では一致。エンジンで実測はまだ）。
PRの実測値は `ecg.measure` と同じやり方（波形のしきい値）で出すので、手計算と数ms ずれることがある。**画面にはこの実測値を出す**。

## 差し替え案：ウェンケバッハがもうできていた場合 → 第8回 モビッツII

同じ「シームレス」の骨組みで作れる。

- 新しい見せ方：**ウェンケバッハと上下2段で並べる**（シリーズ初の構図）。上段はゴムが伸びて切れる、下段は**ゴムが伸びないまま突然切れる**
- 周期を両段でそろえる（どちらも P4つ・QRS3つ、3.2秒）→ 上下が同じ位置で抜けるので比較が一目でわかり、ループもそのまま成立
- 主役：抜ける直前と直後のPRが**同じ**
- 落とし穴：2:1 は分類できない／QRSが広いと下位のブロックの可能性が高い／ペースメーカーの適応になりうる（判断は医師）
