## 各パターンの描き方（モデルの値）
| パターン | 画面のひとこと ＋ 電気ショックの表示 | 描き方 |
|---|---|---|
| ① 単形性VT | 幅の広いQRSが、速く規則正しい ＋「→ 脈なしならショック」 | 幅の広いQRS（約142ms）が 188/分で規則正しく続く |
| ② 多形性VT | QRSの形が、1拍ごとに変わる ＋「→ 脈なしならショック」 | 幅の広いQRSが約225/分。大きさ（0.45〜1.15mV）と向きが1拍ごとに変わる |
| ③ トルサード・ド・ポワント | ねじれるように変わる。QT延長のあと ＋「→ 脈なしならショック」 | QT延長の洞調律（60/分、QT 約0.56秒）→ T波の上から始まり、約240/分で大きさがねじれるように変わる（ねじれの周期 1.25秒）→ 2.6秒で自然に止まる |
| ④ 粗いVF | 不規則で大きな揺れ。QRSが見えない ＋「→ 電気ショック」 | 3〜9Hz（180〜540/分）の不規則で大きな揺れ（約±0.4mV）。P・QRS・Tは見えない |
| ⑤ 細かいVF | 揺れが小さい。時間がたつと小さくなる ＋「→ 電気ショック」 | 3.5〜10Hz の不規則な小さな揺れ（約±0.08mV） |
| ⑥ 心静止 | ほぼまっすぐの線。電極・感度も確認 ＋「→ ショックしない・CPR」 | ほぼまっすぐの線（±0.01mV のごくわずかな揺れ） |
| ⑦ P波だけ | P波はあるのに、QRSがない ＋「→ ショックしない・CPR」 | P波が75/分。QRSはない（P波のみの心静止＝心室静止） |
| ⑧ PEA（ふつうに見える） | 波形はふつうに見えても、脈がない ＋「→ ショックしない・CPR」 | ふつうの形のP・QRS・T（80/分）。脈はない設定 |
| ⑨ PEA（遅く幅広い） | 遅く幅の広いQRS。脈がない ＋「→ ショックしない・CPR」 | 幅の広いQRS（約188ms）が 30/分。脈はない設定 |
| ⑩ 胸骨圧迫中 | 圧迫の揺れで、下の波形が見えない ＋「→ 止めて波形を見る」 | 約110回/分の大きく規則的な揺れが 2.8秒 → 圧迫を止めると、下に粗いVFが見える |

## ナレーション（録音前の台本。数字は画面に出ているので、声では読まない）
- 冒頭：心停止の波形で、まず覚えたいのは、この10パターン。
- ①：幅の広いQRSが、速く規則正しく。単形性の心室頻拍。
- ②：QRSの形が、1拍ごとに変わる。多形性の心室頻拍。
- ③：ねじれるように変わる。トルサード・ド・ポワント。QT延長がきっかけです。
- ④：不規則で大きな揺れ。粗い心室細動。
- ⑤：揺れが小さい、細かい心室細動。心静止と迷ったら、CPRを続けます。
- ⑥：ほぼまっすぐの線、心静止。電極と感度も確かめて。
- ⑦：P波はあるのに、QRSがない。
- ⑧：波形はふつうに見えても、脈がない。無脈性電気活動、PEA。
- ⑨：遅く幅の広いQRSでも、脈がなければPEA。
- ⑩：胸骨圧迫中は、揺れで波形が見えません。止めて、短く確かめます。
- まとめ：電気ショックをするのは、心室細動と、脈のない心室頻拍。

## とくに見てほしい点
1. ①②③に「脈なしならショック」と出す言い方は妥当か（脈のあるVTは同期カルディオバージョン・薬など別の治療）。看護師向けとして、どこまで書くか
2. ③ トルサードを「ショック適応（脈がなければ）」の群に入れたこと。自然に止まる描き方（LITFL：often self terminating）は妥当か
3. ⑤「心静止と迷ったら、CPRを続けます」（ERC 2021）の言い方は、看護師向けに誤解がないか
4. ⑥ 心静止の「電極と感度も確かめて」は妥当か。CPRを遅らせる心配はないか
5. ⑦ P波だけ（心室静止）を入れたことと、「ショックしない・CPR」の表示。ペーシングに触れるべきか
6. ⑧⑨ PEA：「波形はふつうに見えても、脈がない」という教え方。⑨ の描き方（30/分・幅の広いQRS）
7. ⑩ 胸骨圧迫中：「止めて、短く確かめます」とキャプションの「中断はできるだけ短く」。秒数を書くべきか
8. 10パターンの選び方（脈のあるVTとの見分け、ROSC、電気ショック直後の波形、徐脈頻脈などは入れていない）
9. キャプションの最後「まず、反応・呼吸を確認して、人を呼び、CPRを始めてください」の順番と言い方（院内の看護師向け）
