| パターン | 画面のひとこと ＋ 電気ショックの表示 | 描き方 |
|---|---|---|
| ① R on T | T波の上にPVCが乗る。VFのきっかけに ＋「→ すぐ報告」 | 洞調律 75/分。PVC（QRS 約142ms）が直前のRから 0.27秒（T波の頂点）に乗る。1回だけで洞調律に戻る |
| ② PVCの連発 | PVCが3つ以上続く（ショートラン） ＋「→ すぐ報告」 | 洞調律 75/分のあと、PVCが3つ（間隔 0.38秒＝158/分）続いて、洞調律に戻る |
| ③ 単形性VT | 幅の広いQRSが、速く規則正しい ＋「→ 脈なしならショック」 | 幅の広いQRS（約142ms）が 188/分で規則正しく続く |
| ④ 多形性VT | QRSの形が、1拍ごとに変わる ＋「→ 脈なしならショック」 | 幅の広いQRSが約225/分。大きさ（0.45〜1.15mV）と向きが1拍ごとに変わる |
| ⑤ トルサード・ド・ポワント | ねじれるように変わる。QT延長のあと ＋「→ 脈なしならショック」 | QT延長の洞調律（60/分、QT 約0.56秒）→ T波の上から始まり、約240/分で大きさがねじれるように変わる（ねじれの周期 1.25秒）→ 2.6秒で自然に止まる |
| ⑥ 粗いVF | 不規則で大きな揺れ。QRSが見えない ＋「→ 電気ショック」 | 3〜9Hz（180〜540/分）の不規則で大きな揺れ（約±0.4mV）。P・QRS・Tは見えない |
| ⑦ 細かいVF | 揺れが小さい。時間がたつと小さくなる ＋「→ 電気ショック」 | 3.5〜10Hz の不規則な小さな揺れ（約±0.08mV） |
| ⑧ モビッツII型 | PRは同じまま、突然QRSが抜ける ＋「→ すぐ報告」 | 洞調律 75/分、PR 0.16秒で一定。4つめのP波のあとQRSが抜ける（4:3）。抜けたところのR-Rは 1.60秒（P-Pの2倍） |
| ⑨ 完全房室ブロック | PとQRSが別々に動く。とても遅い ＋「→ すぐ報告」 | P波 88/分と、幅の広い心室補充調律（QRS 約188ms）35/分が、関係なく別々に出る |

| ⑪ PEA（ふつうに見える） | 波形はふつうに見えても、脈がない ＋「→ ショックしない・CPR」 | ふつうの形のP・QRS・T（80/分）。脈はない設定 |

## ナレーション（録音前の台本。数字は画面に出ているので、声では読まない）
- 冒頭：致死性不整脈と心停止。まず覚えたいのは、この12パターン。
- ①：T波の上に乗るPVC、R on T。心室頻拍や心室細動のきっかけになることがあります。
- ②：PVCが3つ以上、速く続く。ショートラン、非持続性の心室頻拍です。
- ③：幅の広いQRSが、速く規則正しく。単形性の心室頻拍。
- ④：QRSの形が、1拍ごとに変わる。多形性の心室頻拍。
- ⑤：ねじれるように変わる。トルサード・ド・ポワント。QT延長がきっかけです。止まらずに持続して脈がなければ、電気ショックです。
- ⑥：不規則で大きな揺れ。粗い心室細動。
- ⑦：揺れが小さい、細かい心室細動。心静止と迷ったら、CPRを続けます。
- ⑧：PRは変わらず、突然QRSが抜ける。モビッツII型。完全房室ブロックに進むことがあります。
- ⑨：PとQRSが、別々に動く。完全房室ブロック。補充調律が止まると、心静止になります。
- ⑩：ほぼまっすぐの線、心静止。すぐにCPRを始め、並行して電極と感度も確かめて。
- ⑪：波形はふつうに見えても、脈がない。無脈性電気活動、PEA。
- ⑫：遅く幅の広いQRSでも、脈がなければPEA。
- まとめ：電気ショックをするのは、心室細動と、脈のない心室頻拍。

## とくに見てほしい点
1. タイトル「致死性不整脈と心停止」と、冒頭の一文「致死性不整脈と心停止。まず覚えたいのは、この12パターン。」。心停止の波形（VF・無脈性VT・心静止・PEA）と、そこにつながる不整脈を1本にまとめる言い方として誤解がないか
2. 12パターンの選び方。①R on T・②PVCの連発・⑧モビッツII型・⑨完全房室ブロック を「心停止につながるサイン（すぐ報告）」として足したことは妥当か。ほかに入れるべきもの（洞停止、徐脈頻脈、ブルガダ型、QT延長そのもの など）はあるか
3. ① R on T：PVCを直前のRから0.27秒（T波の頂点）に置いた描き方と、台本「心室頻拍や心室細動のきっかけになることがあります」（LITFL：QT延長の状況でトルサードの引き金）。QT延長に触れるべきか
4. ② PVCの連発：3連（158/分）で「ショートラン、非持続性の心室頻拍」と呼ぶこと。「すぐ報告」でよいか
5. ⑧ モビッツII型：4:3、PR 0.16秒一定、幅の狭いQRSで描いた。代表の形として妥当か（実際は幅の広いQRSが多い、という点をどう扱うか）。台本「完全房室ブロックに進むことがあります」
6. ⑨ 完全房室ブロック：心房88/分・幅の広い補充調律35/分。台本「補充調律が止まると、心静止になります」の言い方
7. ⑧⑨を「すぐ報告」にしたこと（ショック・CPRの表示ではない）。徐脈のアルゴリズム（アトロピン・ペーシング）に触れるべきか
8. 前回のレビューで直したところ（⑤トルサードの台本、⑩心静止の台本と画面、キャプションの初動の順番）が、12パターン版でも正しく残っているか
9. スマホの大きさで、① のT波の上のPVC、⑧ の抜けたP波が読み取れるか。誤解を招く表現はないか
