## 各パターンの描き方（モデルの値）
| パターン | 画面のひとこと | 描き方 |
|---|---|---|
| ① 体動 | 体が動くと、基線が大きく乱れる | 洞調律の上に、0.6〜3Hzの大きくゆっくりした揺れ（約0.4mV）と、ときどき鋭い振れ（0.55〜0.75mV）。ふつうのQRSはそのまま見える |
| ② 筋電図 | 力が入ると、細かく速いギザギザ | 洞調律の上に、20〜60Hzの細かく速いギザギザ（約0.1mV） |
| ③ ふるえ（振戦） | 心房細動に見えても、R-Rは一定 | 洞調律の上に、4.5〜8Hzの細かい不規則な揺れ（約0.06mV）。P波が見えにくく心房細動に見えるが、R-Rは0.80秒で一定 |
| ④ シバリング | 寒さのふるえ。不規則な細かい揺れ | 洞調律の上に、6〜10Hzの不規則な揺れ（約0.16mV、強弱あり） |
| ⑤ 呼吸の揺れ | 呼吸に合わせて、基線がゆっくり上下 | 洞調律の基線が、周期4.0秒（15回/分）で±0.38mVゆっくり上下 |
| ⑥ 交流障害 | 電気機器の影響。細かく規則正しいギザギザ | 洞調律の上に、50Hzの規則正しい細かいギザギザ（±0.06mV） |
| ⑦ 電極の接触不良 | 基線が飛ぶ・一瞬とぎれる | 基線の段差（0.45〜0.65mV、そのあと約0.2秒でゆっくり戻る）と、0.15〜0.2秒の一瞬のとぎれ |
| ⑧ 電極外れ | まっすぐの線。まず患者さんを見る | まっすぐの線が2.7秒（そのあいだも心臓は動いている想定）。外れる・付け直す瞬間に小さな振れ |
| ⑨ 電極の付けまちがい | P波・QRS・T波が、まるごと逆さま | II誘導のP波・QRS・T波がまるごと逆さま（RAとLLの入れかわりを想定、LITFL） |
| ⑩ 偽VT（歯みがき） | VTに見えても、ふつうのQRSが同じ間隔で見える | 約4.5Hz（約270/分）の大きな揺れ（約±0.6mV）。中にふつうのQRS（1.0mV）が0.80秒ごとに見える |
| ⑪ 偽VF（断線） | VFに見えても、ふつうのQRSが同じ間隔で見える | 3〜7Hzの不規則で大きな揺れ（強弱あり）。中にふつうのQRSが0.80秒ごとに見える |
| ⑫ 本物のVT | 幅の広いQRSが続き、ふつうのQRSが消える ＋赤で「→ すぐ報告」 | 本物の心室頻拍：188/分の幅の広いQRS（約142ms）が8拍。そのあいだ、ふつうのQRSは見えない |

## ナレーション（録音前の台本。数字は画面に出ているので、声では読まない）
- 冒頭：ノイズで、まず覚えたいのは、この12パターン。
- ①：体が動くと、基線が大きく乱れます。体動。
- ②：力が入ると、細かいギザギザ。筋電図。
- ③：ふるえで、心房細動に見えることも。でも、R-Rは、一定です。
- ④：寒さのふるえ、シバリング。
- ⑤：呼吸に合わせて、基線がゆっくり揺れる。
- ⑥：細かく、規則正しいギザギザ。交流障害。
- ⑦：電極の接触が悪いと、基線が飛びます。
- ⑧：電極が外れると、まっすぐの線。あわてずに、まず、患者さんを見て。
- ⑨：電極の付けまちがいで、波形がまるごと逆さまに。
- ⑩：歯みがきで、心室頻拍のように見えることも。よく見ると、ふつうのQRSが隠れています。
- ⑪：リード線の断線で、心室細動のように見えることも。ここにも、ふつうのQRSが見えますね。
- ⑫：本物の心室頻拍では、ふつうのQRSが消えます。
- まとめ：ノイズの中に、同じ間隔のQRSが見えたら、ノイズ。まず、患者さんを見てください。

## とくに見てほしい点
1. ③「ふるえで、心房細動に見えることも。R-Rは、一定です」：R-Rが一定なら心房細動ではない、と受け取られる言い方で問題ないか（房室ブロックを伴う心房細動などの例外をどこまで気にするか）
2. ⑥ 交流障害を「電気機器の影響」としたのは妥当か（日本は50Hz／60Hz）
3. ⑧ 電極外れ：「まっすぐの線。まず患者さんを見る」で、本物の心静止を見逃させる心配はないか
4. ⑨ 付けまちがいを「波形がまるごと逆さま」（RAとLLの入れかわり）で代表させてよいか。病棟のモニターでの起こりやすさ
5. ⑩ 偽VT・⑪ 偽VF：「ノイズの中に、同じ間隔でふつうのQRSが見えたらノイズ」という見分け方の教え方は妥当か。⑪を「リード線の断線」としたのは妥当か
6. ⑫ 本物のVTを比べるために入れたことと、「ふつうのQRSが消える」という言い方
7. キャプションの「すぐ報告」の範囲と、「迷ったら、ノイズと決めつけずに報告」という書き方
8. 12パターンの選び方（胸骨圧迫中の波形、電気メス、パルスタップ、T波のダブルカウントなどは入れていない）
9. スマホの大きさで、⑩⑪のノイズの中のQRSが読み取れるか。誤解を招く表現はないか
