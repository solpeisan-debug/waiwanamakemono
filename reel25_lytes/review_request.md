## とくに見てほしい点
### 今回の作り（帯を消さずに、その場で形が変わる）・波の名前について
1. **その場で形が変わる見せ方で、誤解を招かないか**。とくに直接変わるつなぎ目（①→②、②→③、③→④、④→⑤、⑤→⑥、⑦→⑧）：
   - ①→②→③→④→⑤→⑥：高Kの段階が1本の帯の上で続けて変わる。「この順に必ず進む」「段階とK値が対応する」「時間をかけてゆっくり進む（どこかで止まる・待てる）」と読まれないか
     （LITFL：usual order だが、この順とはかぎらず、K値とも一致しない。どの段階でも突然VF・心停止になりうる。画面ではゲージの下に「順番どおりとはかぎらない／どの段階でも急変あり」、まとめの声・最後の画面でも伝えている）
   - ③→④（P波が消えて 60 → 43/分）、④→⑤（QRSが広がる。43/分のまま）、⑤→⑥（サイン波へ溶ける。52/分）：心拍数の変わり方が妥当か
   - ⑦→⑧：低Kが重くなると T波がさらに低く、STが下がり、TとU波がつながる、という見せ方
2. **つなぎを通るつなぎ目**（⑥→⑦、⑧→⑨、⑨→⑩、⑩→⑪、⑪→最後）：灰色の「つなぎ」の洞調律（75/分）を通り、「▶ 次の例」を出してから次の形へ。とくに ⑥サイン波 → つなぎ → ⑦低K（サイン波はクロスフェードで消す・「▶ 次の例（別の病態）」）が、
   「サイン波が自然に（または治療で）正常にもどる」「高Kのあとに低Kになる」といった経過として読まれないか。灰色のつなぎを、パターンの1つや患者さんの経過と取りちがえないか。直接でよいつなぎ目との振り分けは妥当か
3. **波の名前の置き場所（P・Q・R・S・T）**：①の帯の拍に、P（P波の上）・Q（Rの手前の小さなq の左下）・R（R頂点の右）・S（Rのあとのくぼみの右下）・T（T波の上）。
   PDF の①のページで、文字がそれぞれの波を正しく指しているか（Q と S が別の部分を指して見えないか。R を頂点の真上でなく右に置いたこと）
4. **T・U の置き場所**：⑦（T波が低く、うしろにU波）で低いT波の上に小さめの「T」、U波の頂点の上に「U」。⑧（STが下がり、TとU波がつながる）は「U」だけ。文字の位置は妥当か。
   T波とU波の取りちがえ（U波をT波と思う、QT を QU で測る）を招かないか。モニター（II誘導）で U波をこの大きさで描くこと（LITFL：V2〜V3 で最もよく見える）
5. ゲージ（見出し「高Kの心電図変化」、はじめ → 進む、下に「順番どおりとはかぎらない／どの段階でも急変あり」）が形の変化といっしょになめらかに上がること、基準のゴースト・「うすい線＝①基準」を形が変わるあいだは消すこと。誤解はないか
6. 名前が消えた直後、紹介したパターンのコピーが枠へ飛ぶあいだに、帯の拍は次の形へ変わり始める。コピーと帯の両方が動くことで、見分けにくくならないか（PDF のつなぎ目のページ）
7. 声と名前の時間：声は名前が出てから 0.55秒で話し始め、形が変わるあいだは声なし（上の「ナレーション」と「動画の流れ」の秒）。名前・ひとことと声の内容がずれて見えるところはないか

### パターンごと
8. 11パターンの選び方と並び（ジギタリス効果は外した、低Mgはキャプションだけ）。上の6つを「高カリウムの進み方」（LITFL の usual order：T波 → P波・PR → QRS → サイン波）として順に並べたこと
9. ⑥サイン波の描き方（52/分・なめらかな波）と、台本「サイン波。いつ心停止しても、おかしくない。」、画面の色の文字「→ 脈を確認・応援を呼ぶ」。サイン波の心拍数・形はこれでよいか
10. ④「P波消失・徐脈」を1つにまとめたこと（43/分、P波なし、QRS 約112msの補充調律）。高Kの徐脈の代表の形として妥当か
11. ⑤QRS幅の拡大：QRS 約240ms・形がくずれてTとつながる描き方。P波を描いていない（④でP波が消えたあと、という並びのため）
12. ⑦⑧低K：⑦のU波の大きさ（U/T 0.8、LITFL：T波の25%を超えると prominent）、⑧のU/T比・ST低下・「→ すぐ報告」は妥当か
13. ⑨低Ca（STが長く、T波の形は同じ）と ⑩薬剤などのQT延長（T波が遅く幅広い）の描き分け。QTc 510ms・520ms の数値
14. ⑪高Ca（QTc 280ms、STがほとんどない）の描き方
15. 色の文字の割りふり：②〜⑤と⑧「すぐ報告」、⑥「脈を確認・応援を呼ぶ」、⑦⑪「採血の値も確認」、⑨「報告・採血も確認」、⑩「12誘導で確認・報告」。②テント状T波だけでも「すぐ報告」でよいか
16. 台本は1パターン1文（声で3〜4秒）に詰め、くわしい説明は画面のひとこととキャプションにまかせた。短くしたことで、医学的に欠けて誤解を招く文はないか（とくに ⑥、まとめ「高カリウムは、どの段階でも、急に心停止することがある。」）
17. スマホの大きさで、③の平たいP波、⑦のU波が読み取れるか
18. 基準のゴースト（うすい線）：拍をR頂点でそろえて重ねたこと。とくに④⑤（43/分）は基準と心拍数がちがうので、基準の拍をそのパターンの拍の位置に置いている（P波は描かない）。誤解を招かないか
